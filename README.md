# 🚀 LearnStream AI • Next-Gen Educational Learning Platform

An AI-powered learning and assessment platform built for students and lifelong learners, helping them find the best educational content, generate synthesis notes, practice adaptive quizzes, take realistic mock tests, and analyze cognitive mastery.

---

## 🌟 Key Features

### 1. 🔍 Smart Topic Search & Video Hub
- **Instant Search:** Search across computer science, machine learning, physics, math, neuroscience, and web engineering.
- **AI Match Score:** Dynamic relevance percentage (e.g. *98% Match*) calculated from student preferences.
- **Video Analysis Modal:** Curated YouTube lecture video player with interactive chapter timestamps and AI key takeaways.
- **Fast Action Triggers:** Generate structured notes or launch a focused quiz directly from any video card.

### 2. 📝 Auto Notes Generator AI
- **Executive Summaries:** High-yield conceptual overviews.
- **Mathematical Formulations:** Clean LaTeX syntax formatting for governing loss equations, gradients, and bounds.
- **Deep-Dive Sections:** Comprehensive theoretical and practical principles.
- **3D Flippable Flashcards:** Active recall cards with 3D flip animation revealing answers.
- **Export to PDF:** One-click academic report formatting with print-ready stylesheet.

### 3. ⚡ AI Quiz & Recall Zone
- **Interactive Quizzes:** Multiple-choice questions testing core intuition and problem-solving.
- **Explanatory Callouts:** Step-by-step diagnostic feedback on why an answer is correct or incorrect.
- **Sound & Confetti:** Web Audio API sound effects and celebratory particle bursts upon quiz completion.

### 4. 📝 Timed Online Mock Tests & Exam Chamber
- **Authentic Exam Simulator:** Real-time countdown timer with 1-minute audio warnings.
- **Question Palette:** Live tracking of *Answered*, *Marked for Review*, and *Unanswered* questions.
- **Submission Modal:** Comprehensive summary check before finalization.
- **Performance Diagnostics:** Circular accuracy gauge, time elapsed, and question-by-question breakdown with PDF download.

### 5. 🤖 AI Tutor Copilot
- **Pedagogical Assistant:** Available both as a dedicated full screen tab and as a floating widget on any page.
- **Quick Prompts:** Instant starters ("Explain Backpropagation with an analogy", "BatchNorm vs LayerNorm", "Event Loop Microtasks").
- **Streaming & Code:** Character-by-character typing with syntax-highlighted code blocks and one-click copy.

### 6. 📊 Cognitive Performance Diagnostics
- **Mastery Radar Chart:** High-DPI spider web visualizing student scores vs. cohort benchmarks across 6 dimensions.
- **Weekly Trajectory Bar Chart:** Study hours logged against daily 2.0h target lines.
- **Remedial Prescriptions:** Tailored AI recommendations targeting weak areas.

### 7. 🎙️ Voice Search & 🌍 Multi-Language
- **Voice Search Engine:** Web Speech API integration with pulsating voice waveform animation and fallback simulation.
- **6 Supported Languages:** English (🇺🇸), Español (🇪🇸), हिन्दी (🇮🇳), Français (🇫🇷), Deutsch (🇩🇪), 日本語 (🇯🇵).
